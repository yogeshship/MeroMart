# Setup Instructions

## 1. Start Services
- Start Apache Tomcat
- Start MySQL (XAMPP)

## 2. Setup Database
1. Open phpMyAdmin
2. Create database:
   mero_mart_db
3. Click Import
4. Upload:
   database/mero_mart_db.sql

## 3. Run Project
1. Deploy project on Tomcat
2. Open browser:
   http://localhost:8080/MeroMart/contact.jsp

## 4. Test
- Fill contact form
- Submit
- Check phpMyAdmin → contact_messages table
